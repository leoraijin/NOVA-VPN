# Поддержка

Для Windows создайте [GitHub issue](https://github.com/leoraijin/NOVA-VPN/issues). Для Android используйте [отдельный репозиторий](https://github.com/leoraijin/NOVA-VPN-Android).

Укажите версию клиента, версию Windows, активный режим, шаги воспроизведения, ожидаемый и фактический результат. При проблемах маршрутизации добавьте правила сайта и приложения.

Не публикуйте ключи, подписки, пароли, полный экспорт или необработанные bugreports. Перед отправкой журнала удалите секреты и личные данные.

Приватный канал для уязвимостей пока не объявлен. Не создавайте публичный issue с секретными файлами или подробностями, раскрывающими действующие ключи.
