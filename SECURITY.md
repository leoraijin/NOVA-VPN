# Сообщения об уязвимостях

Не публикуйте VPN-конфиги, подписочные ссылки, ключи и персональные логи в публичных Issues или Pull Requests.

На дату аудита (6 октября 2026 года) частный канал для сообщений об уязвимостях не подтверждён. Владельцу следует включить GitHub Private Vulnerability Reporting для репозитория либо указать проверенный частный контакт, который регулярно отслеживается. До этого не отправляйте чувствительные детали публично; запросите у владельца безопасный канал.

Этот файл описывает рекомендуемый порядок, но не утверждает, что GitHub security-настройки уже включены или что канал мониторится.
