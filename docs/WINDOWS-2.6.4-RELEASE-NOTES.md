## NOVA VPN 2.6.4 для Windows

- Назначайте разные VPN-серверы сайтам и приложениям. Правило сайта имеет приоритет над правилом приложения.
- Основной сервер используется для трафика без отдельного назначения. DNS-запросы для выбранного сайта обрабатываются через назначенный выход.
- На медленных системах клиент дольше ждёт готовности VPN-интерфейса и подтверждения маршрута.

Распакуйте Complete.zip целиком. Запустите NOVA VPN.exe для работы без установки или NOVA.VPN.Setup.2.6.4.exe для установки. Ядро и остальные компоненты уже в архиве. Установщик также доступен отдельно.

Маршруты приложений, приоритет сайта, DoH, применение и откат правил проверены через Windows TUN с двумя локальными тестовыми выходами. Установщик собран с тем же ядром sing-box.
