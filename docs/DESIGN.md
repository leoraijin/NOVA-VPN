# Оформление

Тема выбирается в **Настройки → Персонализация**. Основные действия сохраняют расположение.

| Тема | Особенности |
| --- | --- |
| Liquid Glass | Светлая палитра, стеклянные поверхности, размытие и круглая главная кнопка |
| One UI | Мягкие карточки, собственная палитра и крупная кнопка подключения |
| Windows Light | Светлые поверхности и спокойные синие акценты |
| Windows Dark | Тёмные поверхности и контрастные элементы |
| Amber Glass | Тёплые янтарные оттенки и стеклянные материалы |

Это имена визуальных профилей NOVA, а не официальные интерфейсы сторонних производителей.

В 2.3.16 быстрые изменения ползунков объединяются: предпросмотр пересобирается не чаще 30 раз в секунду. Фон и размытие переиспользуются при неизменных параметрах. Ограничение предпросмотра не является заявлением о частоте всех анимаций.

Карта региона в широкой раскладке использует цвета текущей темы. Настройка целевой частоты 120 кадров/с не гарантирует её на любом ПК; текущее измерение не подтвердило 120 FPS. См. [STATUS](STATUS.md).

В 2.3.18 карта интерактивна: наведение выделяет страну, нажатие на страну или маркер выбирает профиль. При нескольких профилях открывается список с HTTPS-задержкой и давностью проверки. Полная карта доступна через «Все серверы на карте»; в узком окне — через «Карта серверов». Маркеры обновляются без пересоздания контуров стран. После трёх минут результат считается устаревшим; свечение отображается только для свежих успешных проверок. Самая быстрая проверенная точка выделяется ярче.
