# NOVA VPN 2.6.2 — отдельные ячейки маршрутизации

- Каждый домен, имя приложения и полный путь редактируется в отдельной ячейке.
- Кнопка «Добавить» создаёт поле, кнопка × удаляет правило.
- Вставка многострочного списка раскладывается по ячейкам без потери соседних правил.
- Формат сохранённых маршрутов, порядок правил и блокировки Zapret сохранены.
- Проверены восемь списков, редактирование, добавление/удаление, вставка, светлая/тёмная тема и узкое окно с увеличенным текстом.

Обновление подготовлено поверх опубликованной 2.6.1. Другие незавершённые изменения локальной ветки разработки в него не включены. Сетевые ядра не пересобирались.
