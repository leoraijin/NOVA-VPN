# NOVA VPN 2.6.11 для Windows

В режиме двух VPN страница «Маршрутизация» показывает сохранённые назначения. Сначала идут сайты, затем приложения. В каждой группе карточки расположены в порядке «Напрямую», «Основной VPN», «VPN-2».

Правила по имени приложения и по полному пути .exe видны в карточках. Изменить назначения можно кнопкой «Назначения серверов».

Для ручной установки распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.11.exe.
