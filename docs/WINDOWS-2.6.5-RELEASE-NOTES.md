# NOVA VPN 2.6.5 для Windows

- На главном экране под подключением — карточка «Два VPN-конфига» с переключателем. «Выбрать два конфига» открывает выбор основного VPN и VPN-2; после включения здесь видны оба сервера и кнопка «Конфиги и маршруты».
- Удалены пункт игрового режима и старый блок со списком приложений в маршрутизации. Назначения приложений доступны в редакторе двух конфигов.
- Действия на странице серверов расположены в сетке с одинаковыми размерами и отступами; длинные подписи переносятся внутри кнопок.

Для установки скачайте **NOVA-VPN-Windows-2.6.5-Complete.zip**, распакуйте целиком и запустите **NOVA.VPN.Setup.2.6.5.exe**. Архив содержит установщик, готовый клиент и VPN-ядро. Отдельный установщик также доступен в выпуске.
