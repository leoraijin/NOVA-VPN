# NOVA VPN 2.6.14 для Windows

В боковом меню появился «Отчёт об ошибках». Доступны две кнопки копирования журнала клиента и VPN-ядра: с запуска приложения и за последние 10 минут. Переподключение не сбрасывает журнал отчёта. Ссылки и распознаваемые секреты маскируются перед добавлением в журнал.

Ручная установка: распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.14.exe.
