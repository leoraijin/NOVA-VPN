# NOVA VPN 2.6.23 для Windows

- На главной и странице серверов появились кнопки **Импорт VPN-конфигов** и **Экспорт VPN-конфигов**. Серверы сохраняются в один JSON-файл вместе с ключами. Импорт показывает предварительный просмотр, сохраняет маршруты и оформление и не добавляет повторно уже имеющиеся конфиги.
- Исправлена проверка карты при включённом VPN: отдельное тестовое ядро разрешает реальные адреса серверов через защищённый DNS, независимо от FakeIP действующего туннеля.
- Точки и прогресс обновляются сразу после каждого результата. Ручная проверка получает приоритет над фоновой, одновременно работают не более двух групп по восемь серверов.
- Завершённая неудачная проверка больше не маскируется серой точкой. Серый остаётся для непроверенных, устаревших результатов и неподдерживаемых типов.

Скачайте **NOVA-VPN-Windows-2.6.23-Complete.zip**: установщик и все необходимые компоненты находятся внутри. Отдельный установщик также доступен.

Файл экспорта серверов содержит ключи доступа. Передавайте его только тому, кому хотите предоставить эти конфиги.

- Со страницы серверов убраны кнопки «Мой VPS» и «Корпоративный прокси».
