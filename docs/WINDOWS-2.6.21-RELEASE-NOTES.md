# NOVA VPN 2.6.21

- Каталог серверов создаёт карточки по мере прокрутки, поиск обновляет список после короткой паузы ввода.
- Карта и список используют общую очередь проверок. Несколько проверок могут использовать один временный процесс sing-box, при этом каждая идёт через свой VPN-выход. Когда карта скрыта, её фоновые проверки останавливаются.
- Редактор обрабатывает изменённую строку. При применении настроек копируются только использованные серверы. Если действующая конфигурация совпадает, назначения сохраняются без перезапуска туннеля.
