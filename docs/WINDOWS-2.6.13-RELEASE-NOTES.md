# NOVA VPN 2.6.13 для Windows

На главной, в блоке состояния подключения, добавлены данные VPN-2: имя сервера, отдельный результат HTTPS-проверки с задержкой и количество сайтов и приложений, назначенных этому серверу. Если второй конфиг ещё не выбран, не используется, изменился или отключён, это указано явно. Результат проверки основного VPN не подменяет состояние VPN-2.

Исправлена верхняя панель маршрутизации: одинаковые интервалы между кнопками и строками, отдельное место под панелью, обрезка прокручиваемого списка по его области. Сайты больше не отображаются поверх кнопок.

Ручная установка: распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.13.exe.
