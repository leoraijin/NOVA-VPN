# Установка и обновления

Скачайте установщик `.exe` из Assets в [последнем выпуске](https://github.com/leoraijin/NOVA-VPN/releases/latest). Архивы Source code не заменяют установщик.

Запустите файл и завершите мастер установки. Для TUN и сетевых компонентов Windows может потребовать права администратора. Добавьте свой профиль в разделе **Серверы**: ключи и подписки в комплект не входят.

## Обновления

Откройте **Настройки → Обновление приложения** или скачайте новый установщик из Releases. Устанавливайте обновление в прежнюю папку. После обновления клиент показывает краткую сводку изменений; полные заметки находятся в Releases.

## Перенос

Экспорт настроек без ключей переносит оформление и правила, но не VPN-профили. Профили переносите отдельно.

Полный экспорт содержит секреты: не прикрепляйте его к публичным issues. Пути к приложениям на другом ПК могут отличаться; проверьте их заново.

Windows-установщик не подходит для Android или Wear OS.
