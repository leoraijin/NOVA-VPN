# NOVA VPN 2.6.12 для Windows

В «Маршрутизации» добавлены отдельные редактируемые карточки «Сайты через VPN-2» и «Приложения через VPN-2». Основные списки и прежние правила по именам и путям приложений сохранены. Пока второй сервер не назначен, карточки предлагают выбрать VPN-2 во вкладке «Серверы».

При совпадении домена, имени или пути приложения в другом окне появляется предупреждение с названием этого окна. Добавление разрешено; запись не переносится и не удаляется из других списков. Нормализуются регистр, ссылки с https://, переменные окружения и полные пути приложений.

В режиме двух VPN отредактируйте строки и нажмите «Применить правила». Конфигурация проверяется до применения; при ошибке прежние настройки и подключение восстанавливаются. Черновик сохраняется при переходах между страницами, но не после закрытия клиента. «Отменить изменения» возвращает сохранённые списки.

Для одинакового селектора приоритет: блокировка, напрямую, VPN-2, основной VPN. Более точные домены и полные пути сохраняют приоритет над общими правилами; прежние правила по имени .exe и портам продолжают работать по прежнему порядку. Имена новых приложений VPN-2 сопоставляются без учёта регистра.

Ручная установка: распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.12.exe.
