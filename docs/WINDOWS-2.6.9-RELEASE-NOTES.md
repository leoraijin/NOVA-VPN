# NOVA VPN 2.6.9 для Windows

- В разделе «Маршрутизация» появились отдельные карточки «Сайты через VPN-2» и «Приложения через VPN-2». Можно добавить домен или выбрать файл .exe, а также удалить правило прямо из карточки.
- Если домен или путь .exe уже назначен другому маршруту, он переносится в выбранную карточку с уведомлением. Повтор в той же карточке оставляет одну запись.

Для установки распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.9.exe.
