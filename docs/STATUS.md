# 2.3.29 Preview — 17 октября 2026

Текущая Windows-ветка использует только Windows 11 Light/Dark. Подробное актуальное описание находится в DESIGN.md. Записи ниже относятся к предыдущим версиям и не описывают текущий набор тем.

Проверены миграция и сохранение темы/масштаба, импорт настроек, меню, отсутствие найденных повторов действий, выбор обоих установленных ядер. Проведён визуальный осмотр Mica в Light/Dark; исправлены границы развёрнутого окна и потеря фокуса после смены темы.

Локальные direct/VLESS проверки: по три успешных цикла передачи данных, штатной остановки и освобождения порта. Проверен жизненный цикл процесса через CoreManager. Windows TUN и реальные серверы исключены из текущей проверки по указанию пользователя. Для экспериментального ядра правила доменов и блокировка рекламы пока недоступны; следует выбрать sing-box. Неподдерживаемые настройки отклоняются до подключения.

Артефакты проверки находятся в work/windows11-desktop и work/reality-windows-smoke полного пакета. Снимки используют демонстрационные данные. Реальные VPN-профили не входят в пакет.
