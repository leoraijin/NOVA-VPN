# NOVA VPN 2.6.22 для Windows

[Скачать полный ZIP](https://github.com/leoraijin/NOVA-VPN/releases/download/v2.6.22/NOVA-VPN-Windows-2.6.22-Complete.zip) или [отдельный установщик](https://github.com/leoraijin/NOVA-VPN/releases/download/v2.6.22/NOVA.VPN.Setup.2.6.22.exe).

Распакуйте ZIP целиком. Запустите установщик из архива или откройте NOVA VPN.exe в распакованной папке.


- Кнопка «Проверить серверы» на карте запускает HTTPS-проверку всех конфигов, показывает прогресс и обновляет точки по мере получения результатов.
- При активном VPN проверка следует маршрутам Windows. Если HTTPS через текущее подключение не подтверждён, карта показывает серую точку. Зелёная точка означает успешную проверку.
