# NOVA VPN 2.6.15 для Windows

В режиме двух VPN явные прямые сайты и прямые приложения, распознанные ядром при DNS-запросе, получают реальные адреса вместо временных адресов туннеля. Это устраняет зависимость таких DNS-ответов от работающего TUN. Уже открытое через TUN соединение может потребовать переподключения.

Проверка выхода повторяется по IP, если основной HTTPS-запрос не прошёл. Результат по IP отмечает, что DNS не подтверждён. Ошибки ядра сохраняются в отчёт. Карта быстрее начинает следующую группу проверок, реже повторяет недавние проверки и раньше завершает попытки без ответа.

При импорте подписки сохраняются XHTTP и SplitHTTP. Для подключения по ним требуется Xray, которого пока нет в Windows-клиенте. Обновите подписку, чтобы вернуть ранее пропущенные записи. Импорт также принимает Base64 с переносами строк.

Ручная установка: распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.15.exe.
