# NOVA VPN 2.6.8 для Windows

- Тумблер «Два VPN-конфига» включает возможность выбрать VPN-2 без обязательного назначения сервера.
- Кнопка «Выбрать сервер» сразу открывает список.
- Точка на карте и сервер в списке предлагают основной VPN или VPN-2 сразу после включения тумблера.

Для установки распакуйте полный архив и запустите NOVA.VPN.Setup.2.6.8.exe.
