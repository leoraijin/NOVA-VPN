# NOVA VPN 2.5.0 — библиотека игр и возврат маршрутов

Обычный выпуск Windows из main.

## Библиотека игр

- Автоматическое чтение локальных установок Steam (включая дополнительные библиотеки), Epic Games, GOG и Riot Games. Дополнительный поиск известных игр через сведения Windows.
- Карточки с названием, источником, локальной обложкой Steam либо значком EXE, поиском и кнопкой «Подобрать конфиг».
- Ручное добавление и уточнение игрового EXE. Установки одной игры в разных папках имеют разные идентификаторы.

## Конфиг только для игры

- Игровой выход привязан к точным полным путям игровых EXE. Общие лаунчеры и всё дерево Steam автоматически не перенаправляются.
- Если обычный VPN уже работал, остальные приложения сохраняют его правила на время сессии. Если VPN был выключен, остальные приложения остаются напрямую; Kill Switch запрещает такой режим до подключения обычного VPN.
- Временное игровое правило выше разрешающих правил сайтов и приложений, но ниже блокировок и служебной обработки DNS. DNS игровых процессов, когда Windows позволяет их определить, получает отдельный выход; общий системный DNS остаётся общей политикой.
- Обычные настройки не переписываются. Правки обычных маршрутов во время игры сохраняются и применяются при завершении сессии.

## Завершение и восстановление

- Ручное отключение, выход из игры с задержкой 6 секунд, удаление конфига/EXE и остановка ядра возвращают обычную политику. Поведение при выходе и обрыве настраивается в карточке.
- При штатном завершении восстанавливается прежнее состояние обычного подключения. При недоступной сети действует обычная настройка автопереподключения.
- Служебный NOVA Core Host владеет Windows Job Object с деревом ядра. При исчезновении родителя завершаются только его ядро и потомки; игра, браузер и сторонние VPN не входят в этот Job.
- После аварии или перезапуска журнал сбрасывается, игровой профиль автоматически не включается. Журнал не содержит ключей или конфигураций. Постоянные маршруты Windows/правила брандмауэра для игрового режима не создаются.

## Подбор и определение сервера

- NOVA умеет читать соединения выбранных игровых EXE через локальный API sing-box: только loopback, случайный порт и секрет авторизации. Для первого определения запустите игру при подключённом обычном профиле NOVA и нажмите определение сервера.
- Выбор учитывает 10 серий, медиану, p95 и долю ответов. До 8 кандидатов; прямой путь проверяется только по разрешению и при выключенном основном VPN.
- TCP — предварительная оценка обнаруженной цели, иногда служебного соединения игры. A2S UDP — ответ совместимого query-порта Rust/CS2; query-порт может отличаться от игрового.
- Для произвольного зашифрованного UDP, включая Fortnite/War Thunder, универсальная точная проба не реализована. Обнаружение адреса не означает измерение пинга матча. При отсутствии подходящей пробы можно назначить конфиг вручную. Меньший пинг не обещается.
- Пробы пока IPv4; полные импортированные JSON-конфиги и экспериментальное Reality-ядро не поддерживают игровой слой.

## Проверки

Проверки манифестов, точных игровых путей, приоритета блокировок, сохранения новых пользовательских правок, журнала восстановления, TCP/UDP с настоящим sing-box, интерфейса и установщика. Отдельный тест принудительно завершает владельца и проверяет завершение его дерева процессов при сохранении постороннего процесса.

В GitHub Windows VM дополнительно проверяется настоящий TUN: игра идёт через отдельный выход, другое приложение — через обычный, после снятия игрового слоя игра возвращается к обычному выходу. Реальные матчи, античиты и физическое отключение питания этими проверками не подтверждаются.

Ядра sing-box 1.13.14, Reality и Zapret не пересобирались; лицензии и исходники сторонних компонентов сохранены в выпуске. Профили и подписки в пакет не входят.
