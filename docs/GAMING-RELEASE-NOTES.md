# NOVA VPN 2.4.0 beta 1 — игровой режим Windows

Первый тестовый выпуск игрового режима. База: стабильная Windows 2.3.36.

- Новая страница «Игровой режим»: Fortnite, War Thunder, Rust, CS2, Dota 2 и выбор произвольного EXE.
- До 8 профилей: отдельные измерительные процессы sing-box, без переключения основного TUN. Для честного прямого сравнения основной VPN и Zapret должны быть выключены.
- TCP CONNECT — предварительная оценка указанной цели. A2S UDP — ответ query-порта совместимого сервера с обработкой challenge. Ни один метод не выдаётся за телеметрию матча.
- 10 серий, медиана, p95, разброс и доля неотвеченных проб. Тайм-аут не считается доказательством потерь игровых пакетов.
- Прямые проверки и прямой выход требуют отдельного разрешения; Kill Switch запрещает их. При сравнении с прямым подключением VPN выбирается только при заметном улучшении без ухудшения хвостов и доли ответов.
- Отдельный игровой outbound, сохранение обычных маршрутов остальных приложений и приоритета блокировок/сайтов. Маршрут закреплён; автоматического переключения посреди матча нет.
- Отмена и удаление временных конфигов, локальная история без адресов целей и секретов, проверка устаревания и смены сети.

## Как попробовать

1. Завершите игру и отключите VPN/Zapret.
2. Откройте «Игровой режим», выберите игру (или EXE), задайте известный адрес и порт цели.
3. Для Rust/CS2 используйте query-порт сервера, поддерживающего A2S. Для остальных игр доступен TCP-тест пользовательской цели региона; порт должен принимать TCP.
4. При необходимости разрешите прямое сравнение, запустите подбор, затем включите режим и запустите игру.
5. Проверьте задержку внутри игры. Завершите игру перед выключением режима.

## Границы выпуска

Автоматическое определение IP сервера матча, каталог региональных измерительных целей, универсальная игровая UDP-телеметрия и собственная сеть ускоряющих узлов ещё не реализованы. Адрес цели вводится вручную. Пробы пока IPv4; полный JSON-конфиг не поддерживается в игровом режиме.

Fortnite и War Thunder имеют шаблоны процессов, но не адаптеры протокола матча. Официальные ICMP-адреса Epic нельзя автоматически считать доступными TCP-целями. Когда цель не отвечает, NOVA не придумывает результат.

Проверены синтетические локальные TCP/UDP-сценарии с настоящим sing-box. Реальные игры, провайдеры и античиты не проверены; снижение пинга не обещается. Это prerelease: стабильный канал обновлений остаётся на прежней версии.

Ядра sing-box, экспериментальный Reality Core и Zapret не менялись. Исходники сторонних компонентов и лицензии сохранены в выпуске.
