# NOVA VPN 2.6.0 — автоматический подбор конфига для игры

Обычный выпуск Windows 2.6.0 из main. Доступен через встроенное обновление; предыдущий 2.5.0 сохранён.

## Как пользоваться

1. Добавьте свои VPN-профили. NOVA находит установленные игры в Steam, Epic, GOG и Riot; EXE также можно добавить вручную.
2. Нажмите «Подобрать конфиг» на карточке. При первом подборе NOVA может запустить игру и до двух минут ждать её соединений.
3. После измерения нажмите «Играть». Если игра уже работает, сначала завершите её сеанс: выход не меняется посреди матча.

Полей для ручного выбора IP, порта, метода или профиля в основном игровом интерфейсе нет.

## Что сравнивается

Проверяются все подходящие пользовательские профили партиями до четырёх. После трёх предварительных серий лучшие кандидаты и текущий выход проходят десять серий по одинаковым целям. Учитываются медиана, p95 и доля отсутствующих ответов. Малое улучшение не заменяет стабильный текущий выход. Прямой путь сравнивается только при выключенном обычном VPN и Kill Switch.

Соединения игры определяются по полным путям EXE через защищённый локальный API sing-box, таблицы TCP IPv4/IPv6 и кратковременный ETW-наблюдатель UDP. Адреса хранятся до 30 минут с привязкой к сети. Это история предыдущего сервера, а не гарантия адреса следующего матча.

TCP отображается как предварительная оценка. A2S — подтверждённый ответ совместимого query-сервера Rust/Source; его порт может отличаться от порта матча. Для произвольного зашифрованного UDP универсального измерения игрового RTT нет. Не получив надёжного результата, NOVA сохраняет обычное подключение.

## Маршрутизация и завершение

Временный выход применяется только к точным путям выбранной игры. Общие лаунчеры не перенаправляются целиком. Блокировки и обработка DNS сохраняют приоритет. При работающем обычном VPN другие приложения сохраняют его правила; при запуске только игрового VPN другие приложения идут напрямую, если это разрешает Kill Switch.

Сессия завершается вручную, после выхода игры, удаления профиля/EXE или обрыва соединения. После завершения возвращаются актуальные обычные правила, включая изменения во время игры. Настройки завершения управляются автоматически. Рекомендация устаревает через пять минут либо после изменения сети, игры, профилей или политики подключения.

NOVA Core Host ограничивает своим Windows Job только собственное дерево ядра. Журнал восстановления не содержит ключей. После аварии временный игровой выход не включается автоматически.

## Состояние проверок

19.10.2026 локально воспроизведён дефект старого HTTP-стенда: чтение ожидало TCP EOF после полного ответа. Исправленный клиент использует Content-Length, отклоняет обрезанный ответ. Асинхронный SOCKS-стенд обслуживает настоящий запрос при 48 незавершённых пробах.

Локально прошли проверки игровой библиотеки, автоматического выбора, точных маршрутов, журнала и дерева собственного ядра, игрового UI и прокрутки. На ноутбуке системный туннель для тестов не запускался. IPv6 loopback блокируется локальной сетевой политикой; эта часть обязательна в GitHub Windows VM.

CI 39251652790 на исправленном исходнике полностью прошёл: IPv6, native ETW, TUN, полный MainWindow/CoreManager цикл и сохранение обычного подключения при невалидном игровом конфиге. Исправлена преждевременная готовность после пересоздания TUN: запуск ожидает Windows-адрес и локальное подтверждение точного правила процесса. Старый CI 39232373560 завершился ошибкой; актуальное подтверждение — https://github.com/leoraijin/NOVA-VPN/actions/runs/39251652790.

Реальные матчи, античиты и полноценная установка в отдельной VM остаются обязательными отдельными проверками. Публикация и скачивание через обновлятор установленной NOVA 2.4.1 проверены: версия, установщик и SHA-256 совпали.

Используются прежние публичные sing-box/Reality/Zapret с лицензиями. Пользовательские подписки и ключи в пакет не входят. HWID и переносимые заголовки по-прежнему только хранятся и переносятся локально.
