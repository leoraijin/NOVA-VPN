# NOVA VPN 2.6.25 для Windows

Скачайте и распакуйте полный архив. Внутри установщик, клиент для запуска без установки и оба VPN-ядра. [Скачать полный архив](https://github.com/leoraijin/NOVA-VPN/releases/download/v2.6.25/NOVA-VPN-Windows-2.6.25-Complete.zip)

- Домены и поддомены с окончанием `.ru` по умолчанию идут напрямую, в том числе когда браузеру назначен VPN или включено несколько VPN.
- Чтобы направить сайт `.ru` через VPN, добавьте домен в список сайтов нужного VPN на странице «Маршрутизация». Правила блокировки имеют приоритет.
- Правило работает с sing-box и Reality Core. Сохранённые списки маршрутов сохраняются при обновлении.

[Скачать отдельный установщик](https://github.com/leoraijin/NOVA-VPN/releases/download/v2.6.25/NOVA.VPN.Setup.2.6.25.exe)
